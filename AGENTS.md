# AGENTS.md

Инструкции для ИИ-агентов в этом репозитории (OpenCode, Claude Code и др.) — единый источник: `CLAUDE.md` подключает этот файл через `@AGENTS.md`, правки вносить сюда.

## Что это

«Второй мозг» для **внешних** Obsidian-хранилищ (одно или несколько): Python-код дистиллирует заметки через OpenAI-совместимое API в карточки и чанки, хранит их в SQLite с FTS5 и отдаёт поиск чату через MCP-сервер. **Существующие заметки не изменять**. Исключение: `capture.py` / `create_note` при `BRAIN_WRITE_ENABLED=true` создаёт только новые заметки в `Telegram/` первого хранилища и индексирует их без LLM; авторизацию выполняет клиент. Проверка записи — `python -m unittest discover -s tests` (временное хранилище/БД).

Поток: `sync.py` (LLM) → `data/brain.db` → `mcp_server.py` (инструменты `search_notes` / `get_chunk` / `get_note` / `list_notes`).

## Перед первым запуском

- `common.py` при **импорте** читает `.env` и валидирует `VAULT_PATH` — без `.env` падает любой запуск (`SystemExit`). В свежем checkout `.env` нет: сначала скопировать из `.env.example`.
- `VAULT_PATH` — один или несколько путей через «;»; относительные считаются от каталога репозитория. В `.env.example` — `../Obsidian Git` (соседний каталог; абсолютный вариант: `D:\-=Personal Share=-\Obsidian\Obsidian Git`).
- `data/brain.db` пересобирается и в git не попадает: в свежем checkout БД нет, до первого полного прогона поиск ничего не найдёт. Первый `python sync.py` — дистилляция всех заметок хранилища (LLM-вызов на каждую, платно). Если где-то осталась БД, созданная до введения префикса хранилища в путях, — удалить: иначе гарантирован полный переиндекс.

## Команды

- `pip install -r requirements.txt`
- `python sync.py --dry-run` — показать, что будет обработано, **без вызовов LLM** (безопасная проверка)
- `python sync.py` — один проход; `python sync.py --watch` — непрерывно (debounce 30 с)
- `python mcp_server.py` — запуск MCP-сервера (обычно его стартует клиент по `.mcp.json`)
- Примеры systemd-юнитов для Linux-сервера — `brain-sync.service` (`sync.py --watch`, демон) и пара `brain-pull.timer` / `brain-pull.service` (раз в 5 минут: `git pull` хранилища + `sync.py`); установка — в комментариях в файлах. Варианты взаимоисключающие.

Проверка изменений — `--dry-run`; отдельных тестов и линтера нет. Кириллический вывод скриптов в PowerShell отображается кракозябрами — это кодировка консоли, а не ошибка кода.

## Устаревшие пути (после переезда)

- Регистрация MCP-сервера — в `.mcp.json` **хранилища** (`Obsidian Git\.mcp.json`), не здесь; путь там (`d:/-=Obsidian GIT=-/Brain/mcp_server.py`) тоже устарел — чтобы MCP заработал, поправить на текущее расположение `mcp_server.py`.
- У хранилища есть собственный `CLAUDE.md` с его правилами (obsidian-git, структура папок; не путать с этим).

## Устройство

- `common.py` — пути, `load_env(skip=...)` (побочный эффект при импорте; MCP ставит `BRAIN_ENV_SKIP=LLM_API_KEY`, поэтому ключ LLM в его окружение не попадает), `VAULTS` (разбор `VAULT_PATH`: несколько путей через «;», относительные — от каталога репозитория; одинаковые имена каталогов хранилищ запрещены), `connect(readonly=False)` (WAL и таймаут 30 с, чтобы чтения из MCP не блокировались записями sync; при обычном подключении прогоняет `schema.sql`, там везде `IF NOT EXISTS`; `readonly=True` — для MCP: `mode=ro` + `PRAGMA query_only`, без DDL/WAL, БД должна уже существовать), стемминг ru/en (PyStemmer), `fts_query()`, `iter_notes()` (исключает `.obsidian`, `.git`, `.trash`, `_resources`, «Блок схемы для документации» — на любой глубине — и файлы `CLAUDE.md`).
- `sync.py` — инкрементально по SHA-256 содержимого: новые/изменённые → LLM → upsert, исчезнувшие и опустевшие → удаление. Заметки длиннее `LLM_MAX_INPUT_CHARS` — map-reduce по секциям. Ошибка одной заметки (LLM или чтение файла) не роняет прогон (rollback/пропуск, продолжаем).
- `schema.sql` — таблицы `notes`, `chunks`, FTS5 `fts_notes`/`fts_chunks`. В FTS кладётся уже стеммированный текст; запрос стеммируется тоже. Изменение схемы = поправить `schema.sql` и удалить `data/brain.db`.
- `prompt.md` — системный промпт дистилляции; `sync.py` добавляет к нему `JSON_HINT`.
- В `search_notes` bm25 с отрицательными оценками (меньше = релевантнее), карточка заметки весит больше её фрагментов.

## Правила

- Комментарии, сообщения и CLI-вывод — на русском, как в существующем коде.
- `.env` (содержит `LLM_API_KEY`) не читать, не печатать, не коммитить; править только `.env.example`. Переменные окружения приоритетнее `.env`.
- Провайдер-агностично: только пакет `openai` с `base_url`; JSON доставать из текста ответа (`parse_card`), без tool calling.
- Пути заметок в БД – `<имя хранилища>/<относительный путь>`, сепаратор `/`, UTF-8; русские имена не транслитерировать.
- Не коммитить без просьбы пользователя.
